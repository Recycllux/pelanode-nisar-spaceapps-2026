# PelaNode NISAR – NASA Space Apps Challenge 2026

This repository will be used for the **NASA Space Apps Challenge 2026** hackathon (14–15 November 2026). Team Recycllux is entering the challenge "Dancing with the SARs" with PelaNode NISAR.

All work in this repository is done during the hackathon.

## Prior work

Earlier exploratory work on NISAR water mapping over the Danube Delta and Lake Srebarna lives in a separate repository: [Recycllux/pelanode-nisar](https://github.com/Recycllux/pelanode-nisar). Anything reused from it will be declared in the project submission under Resources.
